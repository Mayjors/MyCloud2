## 题目描述

<p>给定一个整数，写一个函数来判断它是否是 3&nbsp;的幂次方。如果是，返回 <code>true</code> ；否则，返回 <code>false</code> 。</p>

<p>整数 <code>n</code> 是 3 的幂次方需满足：存在整数 <code>x</code> 使得 <code>n == 3<sup>x</sup></code></p>

<strong>输出：</strong>true

<strong>输出：</strong>false
</pre>

<p><strong>示例 3：</strong></p>

<pre>

<strong>输出：</strong>true
</pre>

<p><strong>示例 4：</strong></p>

## 解法

### 方法一：试除法

> **思考**
>
> 判断 $n$ 是否为 $3$ 的幂。连乘直到溢出再比较亦可，但试除更直接：在 $n>2$ 时若不能被 $3$ 整除则否，否则除以 $3$。最终只剩 $1$ 则为是。 $n\le 1$ 的情况自然落到最后的相等判断。

如果 $n \gt 2$，我们可以不断地将 $n$ 除以 $3$，如果不能整除，说明 $n$ 不是 $3$ 的幂，否则继续除以 $3$，直到 $n$ 小于等于 $2$。如果 $n$ 等于 $1$，说明 $n$ 是 $3$ 的幂，否则不是 $3$ 的幂。

时间复杂度 $O(\log_3n)$，空间复杂度 $O(1)$。

#### Java

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (n > 2) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (n % 3 != 0) {
                // 返回当前子问题或整个问题的计算结果。
                return false;
            }
            n /= 3;
        }
        // 返回当前子问题或整个问题的计算结果。
        return n == 1;
    }
}
```

### 方法二：数学

> **思考**
>
> 试除需 $O(\log n)$ 次除法。 $32$ 位内最大 $3$ 的幂为 $3^{19}=1162261467$，正整数 $n$ 为 $3$ 的幂当且仅当它整除该值。一次取模即可。

如果 $n$ 是 $3$ 的幂，那么 $n$ 最大是 $3^{19} = 1162261467$，因此我们只需要判断 $n$ 是否是 $3^{19}$ 的约数即可。

时间复杂度 $O(1)$，空间复杂度 $O(1)$。

#### Python3

#### Java

```java
class Solution {
    public boolean isPowerOfThree(int n) {
        // 返回当前子问题或整个问题的计算结果。
        return n > 0 && 1162261467 % n == 0;
    }
}
```
