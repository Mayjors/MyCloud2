## 解法

### 方法一：中序遍历

> **思考**
>
> BST 的中序遍历即为升序。只需走到第 $k$ 个被访问的结点，不必列出整棵树。
>
> 用栈模拟一路向左，弹出时将 $k$ 减一，减到 $0$ 即答案。

由于二叉搜索树的性质，中序遍历一定能得到升序序列，因此可以采用中序遍历找出第 k 小的元素。

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stk = new ArrayDeque<>();
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (root != null || !stk.isEmpty()) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (root != null) {
                stk.push(root);
                root = root.left;
            } else {
                root = stk.pop();
                // 判断当前分支条件，处理边界或选择对应转移。
                if (--k == 0) {
                    // 返回当前子问题或整个问题的计算结果。
                    return root.val;
                }
                root = root.right;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return 0;
    }
}
```

### 方法二：预处理结点数

> **思考**
>
> 单次中序已够，但若反复查询而树不变，每次 $O(h+k)$ 仍重复走左链。预处理每棵子树的结点数后，可比较左子树规模与 $k$ 决定向左或向右。
>
> 一次查询变为沿根下行，适合静态树上的多次询问。

预处理每个结点作为根节点的子树的节点数。

这种算法可以用来优化频繁查找第 k 个树、而二叉搜索树本身不被修改的情况。

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        BST bst = new BST(root);
        // 返回当前子问题或整个问题的计算结果。
        return bst.kthSmallest(k);
    }
}

class BST {
    private TreeNode root;
    private Map<TreeNode, Integer> cnt = new HashMap<>();

    public BST(TreeNode root) {
        this.root = root;
        count(root);
    }

    public int kthSmallest(int k) {
        TreeNode node = root;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (node != null) {
            int v = node.left == null ? 0 : cnt.get(node.left);
            // 判断当前分支条件，处理边界或选择对应转移。
            if (v == k - 1) {
                // 返回当前子问题或整个问题的计算结果。
                return node.val;
            }
            // 判断当前分支条件，处理边界或选择对应转移。
            if (v < k - 1) {
                node = node.right;
                k -= (v + 1);
            } else {
                node = node.left;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return 0;
    }

    private int count(TreeNode root) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            // 返回当前子问题或整个问题的计算结果。
            return 0;
        }
        int n = 1 + count(root.left) + count(root.right);
        cnt.put(root, n);
        // 返回当前子问题或整个问题的计算结果。
        return n;
    }
}
```
