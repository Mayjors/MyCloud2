## 题目描述

给你一个整数数组 <code>nums</code> 。如果任一值在数组中出现 <strong>至少两次</strong> ，返回 <code>true</code> ；如果数组中每个元素互不相同，返回 <code>false</code> 。
<p>&nbsp;</p>

<p><strong class="example">示例 1：</strong></p>

<div class="example-block">
<p><span class="example-io"><b>输入：</b>nums = [1,2,3,1]</span></p>

<p><span class="example-io"><b>输出：</b>true</span></p>

<p><strong>解释：</strong></p>

<p>元素 1 在下标 0 和 3 出现。</p>
</div>

<p><strong class="example">示例 2：</strong></p>

<div class="example-block">
<p><span class="example-io"><b>输入：</b>nums = [1,2,3,4]</span></p>

<p><span class="example-io"><b>输出：</b>false</span></p>

<p><strong>解释：</strong></p>

<p>所有元素都不同。</p>
</div>

<p><strong class="example">示例 3：</strong></p>

<div class="example-block">

<p><span class="example-io"><b>输出：</b>true</span></p>
</div>

## 解法

### 方法一：排序

> **思考**
>
> 双重循环比较任意一对元素可行，但 $n$ 较大时偏慢。相等元素在排序后必然相邻。
>
> 为此先排序，再检查相邻两项是否相等。

我们先对数组 `nums` 进行排序。

然后遍历数组，如果存在相邻两个元素相同，说明数组中存在重复元素，直接返回 `true`。

否则，遍历结束，返回 `false`。

时间复杂度 $O(n \times \log n)$。其中 $n$ 是数组 `nums` 的长度。

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        Arrays.sort(nums);
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < nums.length - 1; ++i) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (nums[i] == nums[i + 1]) {
                // 返回当前子问题或整个问题的计算结果。
                return true;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return false;
    }
}
```

### 方法二：哈希表

> **思考**
>
> 排序改变相对次序且为 $O(n\log n)$。只需判定是否出现过，哈希表一次扫描即可。
>
> 元素第二次进入集合则存在重复。

遍历数组，将出现过的元素记录在哈希表 $s$ 中。若元素第二次出现时，说明数组中存在重复元素，直接返回 `true`。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 是数组 `nums` 的长度。

#### Python3

#### Java

```java
class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> s = new HashSet<>();
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int num : nums) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (!s.add(num)) {
                // 返回当前子问题或整个问题的计算结果。
                return true;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return false;
    }
}
```
