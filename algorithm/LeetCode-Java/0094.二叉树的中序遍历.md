## 解法

### 方法一：递归遍历

> **思考**
>
> 中序遍历的顺序是「左、根、右」。树本身按递归定义，因此可以直接递归：先走完左子树，再记录根，再走右子树。 $n \le 100$，最坏 $O(n)$ 的递归栈可以接受。进阶才要求改成迭代。

我们先递归左子树，再访问根节点，接着递归右子树。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 是二叉树的节点数，空间复杂度主要取决于递归调用的栈空间。

#### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private List<Integer> ans = new ArrayList<>();

    public List<Integer> inorderTraversal(TreeNode root) {
        dfs(root);
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }

    private void dfs(TreeNode root) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            return;
        }
        dfs(root.left);
        ans.add(root.val);
        dfs(root.right);
    }
}
```

### 方法二：栈实现非递归遍历

> **思考**
>
> 方法一已经得到正确序列，进阶要去掉系统递归。递归的本质是一路向左，走不动再弹出处理、转向右子树。用显式栈模拟这一过程：有左孩子就压栈下探，否则弹出访问并改走右孩子。顺序与中序相同，空间仍为 $O(n)$。

非递归的思路如下：

1. 定义一个栈 $stk$
2. 将树的左节点依次入栈
3. 左节点为空时，弹出栈顶元素并处理
4. 重复 2-3 的操作

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 是二叉树的节点数，空间复杂度主要取决于栈空间。

#### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        Deque<TreeNode> stk = new ArrayDeque<>();
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (root != null || !stk.isEmpty()) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (root != null) {
                stk.push(root);
                root = root.left;
            } else {
                root = stk.pop();
                ans.add(root.val);
                root = root.right;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
```

### 方法三：Morris 实现中序遍历

> **思考**
>
> 方法二仍把空间留在 $O(h)$。若还要 $O(1)$ 额外空间，可以利用 Morris 的观察：左子树中最右结点的后继本来就是当前根，只是右指针空着。临时把这条空指针接到根上，沿左链走下去；回来时再拆掉。树自身的空指针充当栈，中序顺序不变，空间为 $O(1)$。

Morris 遍历无需使用栈，空间复杂度为 $O(1)$。核心思想是：

遍历二叉树节点，

1. 若当前节点 root 的左子树为空，**将当前节点值添加至结果列表 ans** 中，并将当前节点更新为 `root.right`
2. 若当前节点 root 的左子树不为空，找到左子树的最右节点 prev（也即是 root 节点在中序遍历下的前驱节点）：
    - 若前驱节点 prev 的右子树为空，将前驱节点的右子树指向当前节点 root，并将当前节点更新为 `root.left`。
    - 若前驱节点 prev 的右子树不为空，**将当前节点值添加至结果列表 ans** 中，然后将前驱节点右子树指向空（即解除 prev 与 root 的指向关系），并将当前节点更新为 `root.right`。
3. 循环以上步骤，直至二叉树节点为空，遍历结束。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。其中 $n$ 是二叉树的节点数。

#### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (root != null) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (root.left == null) {
                ans.add(root.val);
                root = root.right;
            } else {
                TreeNode prev = root.left;
                // 在条件成立时继续推进；循环内维护边界或状态。
                while (prev.right != null && prev.right != root) {
                    prev = prev.right;
                }
                // 判断当前分支条件，处理边界或选择对应转移。
                if (prev.right == null) {
                    prev.right = root;
                    root = root.left;
                } else {
                    ans.add(root.val);
                    prev.right = null;
                    root = root.right;
                }
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
```
