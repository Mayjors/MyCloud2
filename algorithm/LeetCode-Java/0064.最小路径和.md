## 题目描述

<p>给定一个包含非负整数的 <code><em>m</em>&nbsp;x&nbsp;<em>n</em></code>&nbsp;网格&nbsp;<code>grid</code> ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。</p>

<p><strong>说明：</strong>每次只能向下或者向右移动一步。</p>

## 解法

### 方法一：动态规划

> **思考**
>
> 从左上走到右下、每步只能向右或向下时，若枚举全部路径再取数字和最小者， $m, n \le 200$，路径条数随格子增长而迅速增加，无法在时限内完成。同一格子会被多条路径反复走到，子问题大量重叠。
>
> 因此走到 $(i, j)$ 的最小路径和，必来自其上方或左方的最优值再加上当前格。用 $f[i][j]$ 记录该值，边界沿唯一方向累加，内部取两侧最小值，按行填表即可。

我们定义 $f[i][j]$ 表示从左上角走到 $(i, j)$ 位置的最小路径和。初始时 $f[0][0] = grid[0][0]$，答案为 $f[m - 1][n - 1]$。

考虑 $f[i][j]$：

- 如果 $j = 0$，那么 $f[i][j] = f[i - 1][j] + grid[i][j]$；
- 如果 $i = 0$，那么 $f[i][j] = f[i][j - 1] + grid[i][j]$；
- 如果 $i \gt 0$ 且 $j \gt 0$，那么 $f[i][j] = \min(f[i - 1][j], f[i][j - 1]) + grid[i][j]$。

最后返回 $f[m - 1][n - 1]$ 即可。

时间复杂度 $O(m \times n)$，空间复杂度 $O(m \times n)$。其中 $m$ 和 $n$ 分别是网格的行数和列数。

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] f = new int[m][n];
        f[0][0] = grid[0][0];
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 1; i < m; ++i) {
            f[i][0] = f[i - 1][0] + grid[i][0];
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int j = 1; j < n; ++j) {
            f[0][j] = f[0][j - 1] + grid[0][j];
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 1; i < m; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 1; j < n; ++j) {
                f[i][j] = Math.min(f[i - 1][j], f[i][j - 1]) + grid[i][j];
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return f[m - 1][n - 1];
    }
}
```
