## 解法

### 方法一：BFS

> **思考**
>
> 从右侧看，每层只看到最右边的节点。 $n\le 100$。层序时先把右孩子入队，则队头就是该层最右节点，记下后即可扫完本层。不必事后再取每层末尾。

我们可以使用广度优先搜索，定义一个队列 $\textit{q}$，将根节点放入队列中。每次从队列中取出当前层的所有节点，对于当前节点，我们先判断右子树是否存在，若存在则将右子树放入队列中；再判断左子树是否存在，若存在则将左子树放入队列中。这样每次取出队列中的第一个节点即为该层的右视图节点。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为二叉树节点个数。

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            // 返回当前子问题或整个问题的计算结果。
            return ans;
        }
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (!q.isEmpty()) {
            ans.add(q.peekFirst().val);
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int k = q.size(); k > 0; --k) {
                TreeNode node = q.poll();
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.right != null) {
                    q.offer(node.right);
                }
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.left != null) {
                    q.offer(node.left);
                }
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
```

### 方法二：DFS

> **思考**
>
> 方法一用队列。先递归右子树再左子树，并带上深度：某深度第一次到达时记下的就是该层最右节点，空间随高度而不是宽度。

使用 DFS 深度优先遍历二叉树，每次先遍历右子树，再遍历左子树，这样每层第一个遍历到的节点即为该层的右视图节点。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为二叉树节点个数。

#### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private List<Integer> ans = new ArrayList<>();

    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }

    private void dfs(TreeNode root, int depth) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            return;
        }
        // 判断当前分支条件，处理边界或选择对应转移。
        if (ans.size() == depth) {
            ans.add(root.val);
        }
        dfs(root.right, depth + 1);
        dfs(root.left, depth + 1);
    }
}
```
