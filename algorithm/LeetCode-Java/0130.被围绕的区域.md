## 题目描述

<p>给你一个 <code>m x n</code> 的矩阵 <code>board</code> ，由若干字符 <code>'X'</code> 和 <code>'O'</code>&nbsp;组成，<strong>捕获</strong> 所有 <strong>被围绕的区域</strong>：</p>

<ul>
	<li><strong>连接：</strong>一个单元格与水平或垂直方向上相邻的单元格连接。</li>
	<li><strong>区域：连接所有&nbsp;</strong><code>'O'</code>&nbsp;的单元格来形成一个区域。</li>
	<li><strong>围绕：</strong>如果一个区域中的所有 <code>'O'</code> 单元格都不在棋盘的边缘，则该区域被包围。这样的区域 <strong>完全</strong> 被 <code>'X'</code> 单元格包围。</li>
</ul>

<p>通过 <strong>原地</strong>&nbsp;将输入矩阵中的所有 <code>'O'</code>&nbsp;替换为 <code>'X'</code> 来 <strong>捕获被围绕的区域</strong>。你不需要返回任何值。</p>

## 解法

### 方法一：DFS

> **思考**
>
> 被包围的 `'O'` 要改成 `'X'`，与边界连通的 `'O'` 必须保留。 $m,n\le 200$。从内部出发判断「是否被围住」要处理整片连通块，且边界情况容易漏。
>
> 与其找被围住的，不如标记与边界相连的：从四条边上的 `'O'` 做 DFS，能走到的都先改成占位，其余 `'O'` 一律变成 `'X'`，占位再改回 `'O'`。

我们可以从矩阵的边界开始，将矩阵边界上的每个 `O` 作为起始点，开始进行深度优先搜索。将搜索到的 `O` 全部替换成 `.`。

然后我们再遍历这个矩阵，对于每个位置：

- 如果是 `.`，则替换成 `O`；
- 否则如果是 `O`，则替换成 `X`。

时间复杂度 $O(m \times n)$，空间复杂度 $O(m \times n)$。其中 $m$ 和 $n$ 分别是矩阵的行数和列数。

```java
class Solution {
    private final int[] dirs = {-1, 0, 1, 0, -1};
    private char[][] board;
    private int m;
    private int n;

    public void solve(char[][] board) {
        m = board.length;
        n = board[0].length;
        this.board = board;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < m; ++i) {
            dfs(i, 0);
            dfs(i, n - 1);
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int j = 0; j < n; ++j) {
            dfs(0, j);
            dfs(m - 1, j);
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < m; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j < n; ++j) {
                // 判断当前分支条件，处理边界或选择对应转移。
                if (board[i][j] == '.') {
                    board[i][j] = 'O';
                } else if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                }
            }
        }
    }

    private void dfs(int i, int j) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O') {
            return;
        }
        board[i][j] = '.';
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int k = 0; k < 4; ++k) {
            dfs(i + dirs[k], j + dirs[k + 1]);
        }
    }
}
```

### 方法二：并查集

> **思考**
>
> 方法一用 DFS 染色区分「与边界连通」。并查集把相邻 `'O'` 连成块，并另设一个超级节点连上所有边界 `'O'`。最后不与超级节点同根的 `'O'` 即被包围。避免递归栈，连通关系更直观。

我们也可以使用并查集，将矩阵边界上的每个 `O` 与一个超级节点 $m \times n$ 相连，将矩阵中的每个 `O` 与其上下左右的 `O` 相连。

然后我们遍历这个矩阵，对于每个位置，如果是 `O`，并且其与超级节点不相连，则将其替换成 `X`。

时间复杂度 $O(m \times n \times \alpha(m \times n))$，空间复杂度 $O(m \times n)$。其中 $m$ 和 $n$ 分别是矩阵的行数和列数， $\alpha$ 是阿克曼函数的反函数。

```java
class Solution {
    private int[] p;

    public void solve(char[][] board) {
        int m = board.length;
        int n = board[0].length;
        p = new int[m * n + 1];
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < p.length; ++i) {
            p[i] = i;
        }
        int[] dirs = {-1, 0, 1, 0, -1};
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < m; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j < n; ++j) {
                // 判断当前分支条件，处理边界或选择对应转移。
                if (board[i][j] == 'O') {
                    // 判断当前分支条件，处理边界或选择对应转移。
                    if (i == 0 || i == m - 1 || j == 0 || j == n - 1) {
                        p[find(i * n + j)] = find(m * n);
                    } else {
                        // 遍历候选元素，按本方案的不变量更新状态。
                        for (int k = 0; k < 4; ++k) {
                            int x = i + dirs[k];
                            int y = j + dirs[k + 1];
                            // 判断当前分支条件，处理边界或选择对应转移。
                            if (board[x][y] == 'O') {
                                p[find(x * n + y)] = find(i * n + j);
                            }
                        }
                    }
                }
            }
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < m; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j < n; ++j) {
                // 判断当前分支条件，处理边界或选择对应转移。
                if (board[i][j] == 'O' && find(i * n + j) != find(m * n)) {
                    board[i][j] = 'X';
                }
            }
        }
    }

    private int find(int x) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (p[x] != x) {
            p[x] = find(p[x]);
        }
        // 返回当前子问题或整个问题的计算结果。
        return p[x];
    }
}
```
