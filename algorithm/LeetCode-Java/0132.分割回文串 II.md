## 解法

### 方法一：动态规划

> **思考**
>
> 只要最少切几刀，不必列出方案。 $n\le 2000$，回溯所有分割不可行。与上一题一样先预处理回文区间。 $f[i]$ 表示前缀 $s[0..i]$ 的最少刀数：枚举最后一个回文段 $s[j..i]$，由 $f[j-1]+1$ 转移；整段已是回文则 $0$ 刀。

我们先预处理得到字符串 $s$ 的每一个子串 $s[i..j]$ 是否为回文串，记录在二维数组 $g[i][j]$ 中，其中 $g[i][j]$ 表示子串 $s[i..j]$ 是否为回文串。

接下来，我们定义 $f[i]$ 表示字符串 $s[0..i-1]$ 的最少分割次数，初始时 $f[i]=i$。

接下来，我们考虑 $f[i]$ 如何进行状态转移。我们可以枚举上一个分割点 $j$，如果子串 $s[j..i]$ 是一个回文串，那么 $f[i]$ 就可以从 $f[j]$ 转移而来。如果 $j=0$，那么说明 $s[0..i]$ 本身就是一个回文串，此时不需要进行分割，即 $f[i]=0$。因此，状态转移方程如下：

$$
f[i]=\min_{0\leq j \leq i}\begin{cases} f[j-1]+1, & \textit{if}\ g[j][i]=\textit{True} \\ 0, & \textit{if}\ g[0][i]=\textit{True} \end{cases}
$$

答案即为 $f[n]$，其中 $n$ 是字符串 $s$ 的长度。

时间复杂度 $O(n^2)$，空间复杂度 $O(n^2)$。其中 $n$ 是字符串 $s$ 的长度。

class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] g = new boolean[n][n];
        // 遍历候选元素，按本方案的不变量更新状态。
        for (var row : g) {
            Arrays.fill(row, true);
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = n - 1; i >= 0; --i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = i + 1; j < n; ++j) {
                g[i][j] = s.charAt(i) == s.charAt(j) && g[i + 1][j - 1];
            }
        }
        int[] f = new int[n];
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < n; ++i) {
            f[i] = i;
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 1; i < n; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j <= i; ++j) {
                // 判断当前分支条件，处理边界或选择对应转移。
                if (g[j][i]) {
                    f[i] = Math.min(f[i], j > 0 ? 1 + f[j - 1] : 0);
                }
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return f[n - 1];
    }
}
