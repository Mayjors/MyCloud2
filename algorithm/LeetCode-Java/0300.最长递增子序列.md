## 题目描述

<p>给你一个整数数组 <code>nums</code> ，找到其中最长严格递增子序列的长度。</p>

<p><strong>子序列&nbsp;</strong>是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，<code>[3,6,2,7]</code> 是数组 <code>[0,3,1,6,2,2,7]</code> 的<span data-keyword="subsequence-array">子序列</span>。</p>
&nbsp;

<p><strong>示例 1：</strong></p>

<pre>
<strong>输入：</strong>nums = [10,9,2,5,3,7,101,18]
<strong>输出：</strong>4
<strong>解释：</strong>最长递增子序列是 [2,3,7,101]，因此长度为 4 。
</pre>

<p><strong>示例 2：</strong></p>

<pre>
<strong>输入：</strong>nums = [0,1,0,3,2,3]
<strong>输出：</strong>4
</pre>

<p><strong>示例 3：</strong></p>

<pre>
<strong>输入：</strong>nums = [7,7,7,7,7,7,7]
<strong>输出：</strong>1
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 2500</code></li>
	<li><code>-10<sup>4</sup> &lt;= nums[i] &lt;= 10<sup>4</sup></code></li>
</ul>

<p>&nbsp;</p>

<p><b>进阶：</b></p>

<ul>
	<li>你能将算法的时间复杂度降低到&nbsp;<code>O(n log(n))</code> 吗?</li>
</ul>

## 解法

### 方法一：动态规划

> **思考**
>
> 子序列须保持相对顺序且严格递增。若枚举全部子序列，长度为 $n$ 时状态过多； $n \le 2500$，故可接受按结尾位置转移。
>
> 以 $nums[i]$ 结尾的最长递增子序列，只依赖于左侧更小的元素。为此定义 $f[i]$ 为该长度，枚举 $j < i$ 且 $nums[j] < nums[i]$，取 $f[j]+1$ 的最大值。每个位置独立成段时长度为 $1$，最终答案为 $\max f$。

我们定义 $f[i]$ 表示以 $nums[i]$ 结尾的最长递增子序列的长度，初始时 $f[i] = 1$，答案为 $f[i]$ 的最大值。

对于 $f[i]$，我们需要枚举 $0 \le j \lt i$，如果 $nums[j] \lt nums[i]$，则 $f[i] = \max(f[i], f[j] + 1)$。

最后的答案即为 $f[i]$ 的最大值。

时间复杂度 $O(n^2)$，空间复杂度 $O(n)$。其中 $n$ 为数组长度。

#### Java

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] f = new int[n];
        Arrays.fill(f, 1);
        int ans = 1;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 1; i < n; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j < i; ++j) {
                // 判断当前分支条件，处理边界或选择对应转移。
                if (nums[j] < nums[i]) {
                    f[i] = Math.max(f[i], f[j] + 1);
                }
            }
            ans = Math.max(ans, f[i]);
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
```

### 方法二：离散化 + 树状数组

> **思考**
>
> 方法一查询「左侧小于 $x$ 的最大 $f[j]$」需线性扫描，整体为 $O(n^2)$。将数值离散化后，该查询变为秩上的前缀最大值，树状数组可在 $O(\log n)$ 内维护。
>
> 按原序遍历每个 $x$：先查询小于 $x$ 的前缀最大长度再写回 $x$ 处，保证只用到左侧信息。因此时间降至 $O(n \log n)$，转移语义与方法一相同。

我们将数组中的元素离散化，然后使用树状数组维护不大于某个元素的最长递增子序列的长度。

遍历数组中的每个元素 $x$，将其离散化，然后在树状数组中查找不大于 $x-1$ 的最长递增子序列的长度 $t$，则 $x$ 的最长递增子序列的长度为 $t+1$，更新答案，并且更新树状数组中 $x$ 的最长递增子序列的长度。

遍历完数组中的所有元素，即可得到答案。

时间复杂度 $O(n \times \log n)$，空间复杂度 $O(n)$。其中 $n$ 为数组长度。

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] s = nums.clone();
        Arrays.sort(s);
        int m = 0;
        int n = s.length;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < n; ++i) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (i == 0 || s[i] != s[i - 1]) {
                s[m++] = s[i];
            }
        }
        BinaryIndexedTree tree = new BinaryIndexedTree(m);
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int x : nums) {
            x = search(s, x, m);
            int t = tree.query(x - 1) + 1;
            tree.update(x, t);
        }
        // 返回当前子问题或整个问题的计算结果。
        return tree.query(m);
    }

    private int search(int[] nums, int x, int r) {
        int l = 0;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (l < r) {
            int mid = (l + r) >> 1;
            // 判断当前分支条件，处理边界或选择对应转移。
            if (nums[mid] >= x) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return l + 1;
    }
}

class BinaryIndexedTree {
    private int n;
    private int[] c;

    public BinaryIndexedTree(int n) {
        this.n = n;
        c = new int[n + 1];
    }

    public void update(int x, int v) {
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (x <= n) {
            c[x] = Math.max(c[x], v);
            x += x & -x;
        }
    }

    public int query(int x) {
        int mx = 0;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (x > 0) {
            mx = Math.max(mx, c[x]);
            x -= x & -x;
        }
        // 返回当前子问题或整个问题的计算结果。
        return mx;
    }
}
```
