## 题目描述

<p>给你一个链表的头节点 <code>head</code> ，判断链表中是否有环。</p>

<p>如果链表中有某个节点，可以通过连续跟踪 <code>next</code> 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 <code>pos</code> 来表示链表尾连接到链表中的位置（索引从 0 开始）。<strong>注意：<code>pos</code> 不作为参数进行传递&nbsp;</strong>。仅仅是为了标识链表的实际情况。</p>

<p><em>如果链表中存在环</em>&nbsp;，则返回 <code>true</code> 。 否则，返回 <code>false</code> 。</p>

## 解法

### 方法一：哈希表

> **思考**
>
> 判断链表是否有环。 $n\le 10^4$。走过的节点放进哈希表，再次出现即有环；走到空则无环。实现直接，空间 $O(n)$。进阶要求常数空间。

我们可以遍历链表，用一个哈希表 $s$ 记录每个节点。当某个节点二次出现时，则表示存在环，直接返回 `true`。否则链表遍历结束，返回 `false`。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 是链表中的节点数。

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        Set<ListNode> s = new HashSet<>();
        // 遍历候选元素，按本方案的不变量更新状态。
        for (; head != null; head = head.next) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (!s.add(head)) {
                // 返回当前子问题或整个问题的计算结果。
                return true;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return false;
    }
}
```

### 方法二：快慢指针

> **思考**
>
> 方法一要用线性额外空间。快指针每次两步、慢指针一步，有环则两者必在环内相遇，无环则快指针先到末尾。只需两个指针。

我们定义快慢指针 $fast$ 和 $slow$，初始时均指向 $head$。

快指针每次走两步，慢指针每次走一步，不断循环。当快慢指针相遇时，说明链表存在环。如果循环结束依然没有相遇，说明链表不存在环。

时间复杂度 $O(n)$，其中 $n$ 是链表中的节点数。空间复杂度 $O(1)$。

#### Java

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            // 判断当前分支条件，处理边界或选择对应转移。
            if (slow == fast) {
                // 返回当前子问题或整个问题的计算结果。
                return true;
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return false;
    }
}
```
