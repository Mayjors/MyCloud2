## 题目描述

<p>序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。</p>

<p>请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。</p>

## 解法

### 方法一：层序遍历

> **思考**
>
> 任意二叉树需能还原空孩子，仅存非空值会丢失结构。层序把空结点写成 $\#$，即可按父子位置重建。
>
> 序列化时队列扩展左右孩子；反序列化按同样顺序给队头结点挂左右子。

我们可以采用层序遍历的方式对二叉树进行序列化，即从根节点开始，依次将二叉树的节点按照从上到下、从左到右的顺序加入队列中，然后将队列中的节点依次出队。如果节点不为空，则将其值加入序列化字符串中，否则加入特殊字符 `#`。最后将序列化字符串返回即可。

反序列化时，我们将序列化字符串按照分隔符进行切分，得到一个字符串数组，然后依次将字符串数组中的元素加入队列中。队列中的元素即为二叉树的节点，我们从队列中依次取出元素，如果元素不为 `#`，则将其转换为整数后作为节点的值，然后将该节点加入队列中，否则将其置为 `null`。最后返回根节点即可。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为二叉树的节点个数。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
public class Codec {

    // Encodes a tree to a single string.
    public String serialize(TreeNode root) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            // 返回当前子问题或整个问题的计算结果。
            return null;
        }
        List<String> ans = new ArrayList<>();
        Deque<TreeNode> q = new LinkedList<>();
        q.offer(root);
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (!q.isEmpty()) {
            TreeNode node = q.poll();
            // 判断当前分支条件，处理边界或选择对应转移。
            if (node != null) {
                ans.add(node.val + "");
                q.offer(node.left);
                q.offer(node.right);
            } else {
                ans.add("#");
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return String.join(",", ans);
    }

    // Decodes your encoded data to tree.
    public TreeNode deserialize(String data) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (data == null) {
            // 返回当前子问题或整个问题的计算结果。
            return null;
        }
        String[] vals = data.split(",");
        int i = 0;
        TreeNode root = new TreeNode(Integer.valueOf(vals[i++]));
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (!q.isEmpty()) {
            TreeNode node = q.poll();
            // 判断当前分支条件，处理边界或选择对应转移。
            if (!"#".equals(vals[i])) {
                node.left = new TreeNode(Integer.valueOf(vals[i]));
                q.offer(node.left);
            }
            ++i;
            // 判断当前分支条件，处理边界或选择对应转移。
            if (!"#".equals(vals[i])) {
                node.right = new TreeNode(Integer.valueOf(vals[i]));
                q.offer(node.right);
            }
            ++i;
        }
        // 返回当前子问题或整个问题的计算结果。
        return root;
    }
}
