## 解法

### 方法一：头插法

> **思考**
>
> 把结点依次放入数组再反向重建可行，但只需改指针。头插可在一次遍历中完成反转：当前结点不断插到哑结点之后。
>
> 遍历结束时 $\textit{dummy.next}$ 即为新头，空间为常数。

我们创建一个虚拟头节点 $\textit{dummy}$，然后遍历链表，将每个节点依次插入 $\textit{dummy}$ 的下一个节点。遍历结束，返回 $\textit{dummy.next}$。

时间复杂度 $O(n)$，其中 $n$ 为链表的长度。空间复杂度 $O(1)$。

#### Java

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode dummy = new ListNode();
        ListNode curr = head;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = dummy.next;
            dummy.next = curr;
            curr = next;
        }
        // 返回当前子问题或整个问题的计算结果。
        return dummy.next;
    }
}
```

### 方法二：递归

> **思考**
>
> 头插已是线性迭代。也可先递归反转后继链表，再把当前结点接到新尾之后。
>
> 指针操作更短，但系统栈占用 $O(n)$ 空间。

递归反转链表的第二个节点到尾部的所有节点，然后 $head$ 插在反转后的链表的尾部。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为链表的长度。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (head == null || head.next == null) {
            // 返回当前子问题或整个问题的计算结果。
            return head;
        }
        ListNode ans = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
```
