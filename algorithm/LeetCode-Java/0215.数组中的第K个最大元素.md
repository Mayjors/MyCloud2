## 题目描述

<p>给定整数数组 <code>nums</code> 和整数 <code>k</code>，请返回数组中第 <code><strong>k</strong></code> 个最大的元素。</p>

<p>请注意，你需要找的是数组排序后的第 <code>k</code> 个最大的元素，而不是第 <code>k</code> 个不同的元素。</p>

<p>你必须设计并实现时间复杂度为 <code>O(n)</code> 的算法解决此问题。</p>

<p>&nbsp;</p>

<p><strong>示例 1:</strong></p>

<pre>
<strong>输入:</strong> <code>[3,2,1,5,6,4],</code> k = 2
<strong>输出:</strong> 5
</pre>

<p><strong>示例&nbsp;2:</strong></p>

<pre>
<strong>输入:</strong> <code>[3,2,3,1,2,4,5,5,6], </code>k = 4
<strong>输出:</strong> 4</pre>

<p>&nbsp;</p>

<p><strong>提示： </strong></p>

<ul>
	<li><code>1 &lt;= k &lt;= nums.length &lt;= 10<sup>5</sup></code></li>
	<li><code>-10<sup>4</sup>&nbsp;&lt;= nums[i] &lt;= 10<sup>4</sup></code></li>
</ul>

## 解法

### 方法一：快速选择

> **思考**
>
> 全排序后取第 $k$ 大可行，但多做了对其余位置的排序。快速选择只关心第 $k$ 大所在的那一侧。
>
> 每次按基准划分后，仅递归包含目标名次的区间。实现上将第 $k$ 大转为第 $n-k$ 小。

快速选择算法是一种在未排序的数组中查找第 `k` 个最大元素或最小元素的算法。它的基本思想是每次选择一个基准元素，将数组分为两部分，一部分的元素都比基准元素小，另一部分的元素都比基准元素大，然后根据基准元素的位置，决定继续在左边还是右边查找，直到找到第 `k` 个最大元素。

时间复杂度 $O(n)$，空间复杂度 $O(\log n)$。其中 $n$ 为数组 $\textit{nums}$ 的长度。

```java
class Solution {
    private int[] nums;
    private int k;

    public int findKthLargest(int[] nums, int k) {
        this.nums = nums;
        this.k = nums.length - k;
        // 返回当前子问题或整个问题的计算结果。
        return quickSort(0, nums.length - 1);
    }

    private int quickSort(int l, int r) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (l == r) {
            // 返回当前子问题或整个问题的计算结果。
            return nums[l];
        }
        int i = l - 1, j = r + 1;
        int x = nums[(l + r) >>> 1];
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (i < j) {
            // 在条件成立时继续推进；循环内维护边界或状态。
            while (nums[++i] < x) {
            }
            // 在条件成立时继续推进；循环内维护边界或状态。
            while (nums[--j] > x) {
            }
            // 判断当前分支条件，处理边界或选择对应转移。
            if (i < j) {
                int t = nums[i];
                nums[i] = nums[j];
                nums[j] = t;
            }
        }
        // 判断当前分支条件，处理边界或选择对应转移。
        if (j < k) {
            // 返回当前子问题或整个问题的计算结果。
            return quickSort(j + 1, r);
        }
        // 返回当前子问题或整个问题的计算结果。
        return quickSort(l, j);
    }
}
```

### 方法二：优先队列（小根堆）

> **思考**
>
> 快速选择平均线性，最坏可达平方。若只需第 $k$ 大，可维护大小为 $k$ 的小根堆。
>
> 扫过数组后堆中为最大的 $k$ 个数，堆顶即第 $k$ 大，时间为 $O(n\log k)$。

我们可以维护一个大小为 $k$ 的小根堆 $\textit{minQ}$，然后遍历数组 $\textit{nums}$，将数组中的元素依次加入到小根堆中，当小根堆的大小超过 $k$ 时，我们将堆顶元素弹出，这样最终小根堆中的 $k$ 个元素就是数组中的 $k$ 个最大元素，堆顶元素就是第 $k$ 个最大元素。

时间复杂度 $O(n\log k)$，空间复杂度 $O(k)$。其中 $n$ 为数组 $\textit{nums}$ 的长度。

#### Python3

#### Java

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minQ = new PriorityQueue<>();
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int x : nums) {
            minQ.offer(x);
            // 判断当前分支条件，处理边界或选择对应转移。
            if (minQ.size() > k) {
                minQ.poll();
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return minQ.peek();
    }
}
```

### 方法三：计数排序

> **思考**
>
> 堆仍有对数因子。值域有界时，先统计每个值的出现次数，再从大到小累加次数，直到凑满 $k$。
>
> 时间与数组长度及值域上界成正比，无需比较排序。

我们可以使用计数排序的思想，统计数组 $\textit{nums}$ 中每个元素出现的次数，记录在哈希表 $\textit{cnt}$ 中，然后从大到小遍历元素 $i$，每次减去出现的次数 $\textit{cnt}[i]$，直到 $k$ 小于等于 $0$，此时的元素 $i$ 就是数组中的第 $k$ 个最大元素。

时间复杂度 $O(n + m)$，空间复杂度 $O(n)$。其中 $n$ 为数组 $\textit{nums}$ 的长度，而 $m$ 为数组 $\textit{nums}$ 中元素的最大值。

#### Java

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        Map<Integer, Integer> cnt = new HashMap<>(nums.length);
        int m = Integer.MIN_VALUE;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int x : nums) {
            m = Math.max(m, x);
            cnt.merge(x, 1, Integer::sum);
        }
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = m;; --i) {
            k -= cnt.getOrDefault(i, 0);
            // 判断当前分支条件，处理边界或选择对应转移。
            if (k <= 0) {
                // 返回当前子问题或整个问题的计算结果。
                return i;
            }
        }
    }
}
```
