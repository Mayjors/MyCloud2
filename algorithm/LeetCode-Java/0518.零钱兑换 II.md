## 题目描述

<p>给你一个整数数组 <code>coins</code> 表示不同面额的硬币，另给一个整数 <code>amount</code> 表示总金额。</p>

<p>请你计算并返回可以凑成总金额的硬币组合数。如果任何硬币组合都无法凑出总金额，返回 <code>0</code> 。</p>

<p>假设每一种面额的硬币有无限个。&nbsp;</p>

<p>题目数据 <strong>保证</strong> <b>最终</b>&nbsp;结果符合 <strong>32 位&nbsp;</strong>带符号整数。</p>

## 解法

### 方法一：动态规划(完全背包)

> **思考**
>
> 求凑成 `amount` 的组合数，顺序不同视为同一种。若按排列计数会把同一组合算多次。
>
> 这是完全背包的方案数：外层枚举硬币、内层枚举金额，使每种硬币只按一种顺序加入。 $f[i][j]$ 表示用前 $i$ 种硬币凑 $j$ 的方案数，不选第 $i$ 种继承 $f[i-1][j]$，选则加上 $f[i][j-x]$。 $f[0][0]=1$ 作为空组合。

我们定义 $f[i][j]$ 表示使用前 $i$ 种硬币，凑出金额 $j$ 的硬币组合数。初始时 $f[0][0] = 1$，其余位置的值均为 $0$。

我们可以枚举使用的最后一枚硬币的数量 $k$，那么有式子一：

$$
f[i][j] = f[i - 1][j] + f[i - 1][j - x] + f[i - 1][j - 2 \times x] + \cdots + f[i - 1][j - k \times x]
$$

其中 $x$ 表示第 $i$ 种硬币的面值。

不妨令 $j = j - x$，那么有式子二：

$$
f[i][j - x] = f[i - 1][j - x] + f[i - 1][j - 2 \times x] + \cdots + f[i - 1][j - k \times x]
$$

将式子二代入式子一，得到：

$$
f[i][j] = f[i - 1][j] + f[i][j - x]
$$

最终的答案为 $f[m][n]$，其中 $m$ 和 $n$ 分别表示硬币的种类数和总金额。

时间复杂度 $O(m \times n)$，空间复杂度 $O(m \times n)$。其中 $m$ 和 $n$ 分别为硬币的种类数和总金额。

#### Java

```java
class Solution {
    public int change(int amount, int[] coins) {
        int m = coins.length, n = amount;
        int[][] f = new int[m + 1][n + 1];
        f[0][0] = 1;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 1; i <= m; ++i) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = 0; j <= n; ++j) {
                f[i][j] = f[i - 1][j];
                // 判断当前分支条件，处理边界或选择对应转移。
                if (j >= coins[i - 1]) {
                    f[i][j] += f[i][j - coins[i - 1]];
                }
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return f[m][n];
    }
}
```

### 方法二：动态规划优化

> **思考**
>
> 二维表中 $f[i][j]$ 只依赖上一行的 $j$ 与本行的 $j-x$。压缩成一维后，对每枚硬币从 $x$ 扫到 `amount`，正序累加即可复用本硬币已更新的状态。
>
> 空间降为 $O(\textit{amount})$，转移次数不变。

我们注意到 $f[i][j]$ 只与 $f[i - 1][j]$ 和 $f[i][j - x]$ 有关，因此我们可以将二维数组优化为一维数组，空间复杂度降为 $O(n)$。时间复杂度仍为 $O(m \times n)$。

#### Java

```java
class Solution {
    public int change(int amount, int[] coins) {
        int n = amount;
        int[] f = new int[n + 1];
        f[0] = 1;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int x : coins) {
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int j = x; j <= n; ++j) {
                f[j] += f[j - x];
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return f[n];
    }
}
```
