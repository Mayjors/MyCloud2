## 解法

### 方法一：哈希表 + 递归

> **思考**
>
> 前序给出根的出现顺序，中序给出每个根左右子树的分界。每次在中序里线性扫描根的位置，总时间可达 $O(n^2)$； $n \le 3000$ 偏紧。
>
> 题目保证节点值互不相同，因此中序位置可以预处理进哈希表，查找变为 $O(1)$。前序区间的首元素是根，中序中该值左侧是左子树、右侧是右子树，长度确定后再递归构造两段。

前序序列的第一个节点 $preorder[0]$ 为根节点，我们在中序序列中找到根节点的位置 $k$，可以将中序序列划分为左子树 $inorder[0..k]$ 、右子树 $inorder[k+1..]$。

通过左右子树的区间，可以计算出左、右子树节点的个数，假设为 $a$ 和 $b$。然后在前序节点中，从根节点往后的 $a$ 个节点为左子树，再往后的 $b$ 个节点为右子树。

因此，我们设计一个函数 $dfs(i, j, n)$，其中 $i$ 和 $j$ 分别表示前序序列和中序序列的起始位置，而 $n$ 表示节点个数。函数的返回值是以 $preorder[i..i+n-1]$ 为前序序列，以 $inorder[j..j+n-1]$ 为中序序列构造出的二叉树。

函数 $dfs(i, j, n)$ 的执行过程如下：

- 如果 $n \leq 0$，说明没有节点，返回空节点。
- 取出前序序列的第一个节点 $v = preorder[i]$ 作为根节点，然后利用哈希表 $d$ 找到根节点在中序序列中的位置 $k$，那么左子树的节点个数为 $k - j$，右子树的节点个数为 $n - k + j - 1$。
- 递归构造左子树 $l = dfs(i + 1, j, k - j)$ 和右子树 $r = dfs(i + 1 + k - j, k + 1, n - k + j - 1)$。
- 最后返回以 $v$ 为根节点且左右子树分别为 $l$ 和 $r$ 的二叉树。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为二叉树节点个数。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int[] preorder;
    private Map<Integer, Integer> d = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        int n = preorder.length;
        this.preorder = preorder;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < n; ++i) {
            d.put(inorder[i], i);
        }
        // 返回当前子问题或整个问题的计算结果。
        return dfs(0, 0, n);
    }

    private TreeNode dfs(int i, int j, int n) {
        // 判断当前分支条件，处理边界或选择对应转移。
        if (n <= 0) {
            // 返回当前子问题或整个问题的计算结果。
            return null;
        }
        int v = preorder[i];
        int k = d.get(v);
        TreeNode l = dfs(i + 1, j, k - j);
        TreeNode r = dfs(i + 1 + k - j, k + 1, n - 1 - (k - j));
        // 返回当前子问题或整个问题的计算结果。
        return new TreeNode(v, l, r);
    }
}

### 方法二：哈希表 + 递归（节点值可重复）

> **思考**
>
> 方法一依赖「值唯一」才能用单个下标定位根。若值可重复，同一值在中序中可能有多个合法位置，必须记录全部下标并枚举落在当前区间内的每一个，分别递归左右子树再做笛卡尔组合。本题本身不需要这条分支，它回答的是值可重复时如何穷举所有可行树。

本题保证节点值互不相同。如果节点值可以重复，哈希表需要记录每个值出现的所有位置，并枚举当前区间内每一个可能的根位置，递归构造出所有可能的二叉树。

时间复杂度和空间复杂度均与可行二叉树的数量相关（需要构造并保存全部结果），最坏情况下为指数级。递归栈额外占用 $O(n)$ 空间。

class Solution {
    private List<Integer> preorder;
    private Map<Integer, List<Integer>> d = new HashMap<>();

    public List<TreeNode> getBinaryTrees(List<Integer> preOrder, List<Integer> inOrder) {
        int n = preOrder.size();
        this.preorder = preOrder;
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int i = 0; i < n; ++i) {
            d.computeIfAbsent(inOrder.get(i), k -> new ArrayList<>()).add(i);
        }
        // 返回当前子问题或整个问题的计算结果。
        return dfs(0, 0, n);
    }

    private List<TreeNode> dfs(int i, int j, int n) {
        List<TreeNode> ans = new ArrayList<>();
        // 判断当前分支条件，处理边界或选择对应转移。
        if (n <= 0) {
            ans.add(null);
            // 返回当前子问题或整个问题的计算结果。
            return ans;
        }
        int v = preorder.get(i);
        // 遍历候选元素，按本方案的不变量更新状态。
        for (int k : d.get(v)) {
            // 判断当前分支条件，处理边界或选择对应转移。
            if (k >= j && k < j + n) {
                // 遍历候选元素，按本方案的不变量更新状态。
                for (TreeNode l : dfs(i + 1, j, k - j)) {
                    // 遍历候选元素，按本方案的不变量更新状态。
                    for (TreeNode r : dfs(i + 1 + k - j, k + 1, n - 1 - (k - j))) {
                        ans.add(new TreeNode(v, l, r));
                    }
                }
            }
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
