## 题目描述

<p>给你二叉树的根节点 <code>root</code> ，返回其节点值的 <strong>锯齿形层序遍历</strong> 。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。</p>

## 解法

### 方法一：BFS

> **思考**
>
> 与普通层序相比，奇数层仍从左到右，偶数层要从右到左。若按层建好后再整体反转部分层，时间仍是 $O(n)$。 $n \le 2000$ 可以接受。
>
> 因此仍用队列做层序，额外用一个方向标志：本层收集完毕后，若当前方向为右到左，则反转该层再写入答案，并翻转标志。孩子始终按从左到右入队，下一层的遍历顺序不受影响。

为了实现锯齿形层序遍历，需要在层序遍历的基础上增加一个标志位 `left`，用于标记当前层的节点值的顺序。如果 `left` 为 `true`，则当前层的节点值按照从左到右的顺序存入结果数组 `ans` 中；如果 `left` 为 `false`，则当前层的节点值按照从右到左的顺序存入结果数组 `ans` 中。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 为二叉树的节点数。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            // 返回当前子问题或整个问题的计算结果。
            return ans;
        }
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        boolean left = true;
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (!q.isEmpty()) {
            List<Integer> t = new ArrayList<>();
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int n = q.size(); n > 0; --n) {
                TreeNode node = q.poll();
                t.add(node.val);
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.left != null) {
                    q.offer(node.left);
                }
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.right != null) {
                    q.offer(node.right);
                }
            }
            // 判断当前分支条件，处理边界或选择对应转移。
            if (!left) {
                Collections.reverse(t);
            }
            ans.add(t);
            left = !left;
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
