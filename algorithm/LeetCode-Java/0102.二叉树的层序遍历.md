## 解法

### 方法一：BFS

> **思考**
>
> 题目要按层输出节点值。深度优先也能记下深度再分组，但同一层的左右顺序还要额外整理。 $n \le 2000$，一层最多 $O(n)$ 个节点。
>
> 广度优先天然按层扩张：队列中当前一批节点恰为一层，出队时收集取值并压入孩子，即可得到从左到右的一层结果。

我们可以使用 BFS 的方法来解决这道题。首先将根节点入队，然后不断地进行以下操作，直到队列为空：

- 遍历当前队列中的所有节点，将它们的值存储到一个临时数组 $t$ 中，然后将它们的孩子节点入队。
- 将临时数组 $t$ 存储到答案数组中。

最后返回答案数组即可。

时间复杂度 $O(n)$，空间复杂度 $O(n)$。其中 $n$ 是二叉树的节点个数。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        // 判断当前分支条件，处理边界或选择对应转移。
        if (root == null) {
            // 返回当前子问题或整个问题的计算结果。
            return ans;
        }
        Deque<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        // 在条件成立时继续推进；循环内维护边界或状态。
        while (!q.isEmpty()) {
            List<Integer> t = new ArrayList<>();
            // 遍历候选元素，按本方案的不变量更新状态。
            for (int n = q.size(); n > 0; --n) {
                TreeNode node = q.poll();
                t.add(node.val);
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.left != null) {
                    q.offer(node.left);
                }
                // 判断当前分支条件，处理边界或选择对应转移。
                if (node.right != null) {
                    q.offer(node.right);
                }
            }
            ans.add(t);
        }
        // 返回当前子问题或整个问题的计算结果。
        return ans;
    }
}
