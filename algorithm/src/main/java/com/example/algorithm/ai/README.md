## 核心考点

### 字节面试重点考察的能力

1. **代码实现能力** - 能否快速准确地写出 bug-free 的代码
2. **算法思维** - 能否分析问题并选择合适的算法
3. **复杂度分析** - 能否分析时间和空间复杂度
4. **边界处理** - 能否考虑各种边界情况
5. **代码规范** - 代码是否清晰易读

### 高频考点总结

- **数组/字符串**: 双指针、滑动窗口、前缀和
- **链表**: 快慢指针、虚拟头结点、反转
- **树**: DFS、BFS、递归
- **动态规划**: 状态定义、状态转移方程
- **回溯**: 决策树、剪枝优化
- **堆/栈**: 单调栈、优先队列

## 使用建议

1. **按分类刷题** - 先掌握一类题型，再攻克下一类
2. **理解思路** - 不要死记硬背，理解解题思路
3. **手写代码** - 面试时要手写，平时多练习
4. **分析复杂度** - 每道题都要会分析时间/空间复杂度
5. **总结规律** - 相似题目要总结共同点

## 难度说明

- ⭐ 简单 - 基础题，必须掌握
- ⭐⭐ 中等 - 常考题，重点练习
- ⭐⭐⭐ 困难 - 高频难题，深入理解
